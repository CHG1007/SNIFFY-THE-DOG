### 1-5. 빌드 및 배포 절차

#### 소스 클론

```bash
git clone https://lab.ssafy.com/s14-webmobile1-sub1/S14P11A407.git
cd S14P11A407
```

#### Backend 빌드 (로컬)

```bash
cd back
chmod +x gradlew
./gradlew clean bootJar -x test
```

- 빌드 산출물: `back/bootstrap/build/libs/*.jar`

#### Frontend 빌드 (로컬)

```bash
cd front
npm ci
VITE_KAKAO_JS_KEY=<카카오_JS_키> VITE_LIVEKIT_URL=wss://<도메인>/livekit/ npm run build
```

- 빌드 산출물: `front/dist/`

#### Docker 이미지 빌드

```bash
# Backend 이미지
docker build -t a407_back:latest -f back/Dockerfile back

# Nginx 이미지
docker build -t a407_nginx:latest -f nginx/Dockerfile nginx
```

#### 배포 서버 준비

1. 배포 서버에 Docker, Docker Compose 설치
2. 배포 경로 생성 (예: `/home/ubuntu/app`)
3. 아래 파일들을 배포 경로에 배치:
   - `docker-compose.yml`
   - `nginx.conf` (envsubst로 `${SERVER_NAME}` 치환 완료된 파일)
   - `livekit.yaml` (envsubst로 API 키/시크릿 치환 완료된 파일)
   - `frontend/` 디렉토리 (프론트엔드 빌드 산출물)
   - `.env` 파일 (환경 변수)

#### .env 파일 예시

```env
BACKEND_IMAGE=<docker_username>/a407_back
NGINX_IMAGE=<docker_username>/a407_nginx
IMAGE_TAG=latest

MYSQL_ROOT_PASSWORD=<MySQL_root_비밀번호>
MYSQL_DATABASE=sniffy
MYSQL_USER=sniffy
MYSQL_PASSWORD=<MySQL_비밀번호>

MONGO_USER=<MongoDB_사용자명>
MONGO_PASSWORD=<MongoDB_비밀번호>
MONGO_DATABASE=sniffythedog

KAKAO_REST_API_KEY=<카카오_REST_API_키>
KAKAO_JS_KEY=<카카오_JS_키>
JWT_SECRET=<JWT_시크릿>
GMS_API_KEY=<GMS_API_키>

LIVEKIT_API_KEY=<LiveKit_API_키>
LIVEKIT_API_SECRET=<LiveKit_API_시크릿>

SERVER_NAME=<서비스_도메인>
```

#### Docker Compose 실행

```bash
cd /home/ubuntu/app

# DB 먼저 기동 (데이터 유지)
docker compose up -d --no-recreate mysql redis mongodb

# 앱 서비스 기동
docker compose up -d --force-recreate --no-deps backend nginx livekit certbot
```

#### SSL 인증서 최초 발급

```bash
# certbot 컨테이너에서 실행
docker exec certbot certbot certonly --webroot -w /var/www/certbot \
  -d <서비스_도메인> --agree-tos --email <이메일>
```

- 인증서는 certbot 컨테이너가 12시간마다 자동 갱신
- Nginx는 6시간마다 설정 리로드

### 1-6. 배포 시 특이사항

1. **CI/CD 자동 배포**: `develop` 브랜치에 push하면 GitLab CI가 자동으로 테스트 -> 빌드 -> 배포를 수행
2. **Docker Hub**: 이미지는 Docker Hub에 push 후 배포 서버에서 pull하는 방식
3. **LiveKit 포트**: LiveKit은 UDP 30000-30100 포트를 사용하므로 배포 서버의 보안 그룹/방화벽에서 해당 포트를 열어야 함
4. **SSL 최초 설정**: 최초 배포 시 SSL 인증서가 없으므로, 먼저 HTTP로 Nginx를 기동한 뒤 certbot으로 인증서를 발급받아야 함
5. **Frontend 빌드 산출물**: Frontend는 Docker 이미지에 포함되지 않고, 배포 시 `frontend/` 디렉토리를 Nginx 볼륨으로 마운트
6. **Nginx 설정 템플릿**: `nginx.conf`는 `${SERVER_NAME}` 변수를 사용하므로 배포 전 `envsubst`로 치환 필요
7. **Health Check**: Backend 컨테이너는 `/actuator/health` 엔드포인트로 헬스체크를 수행 (10초 간격, 30초 대기)
8. **멀티모듈 구조**: Backend는 Hexagonal Architecture 기반 Gradle 멀티모듈로 구성되어 있으며, `bootstrap` 모듈에서 최종 JAR가 생성됨

## 2. 외부 서비스 정보

### 2-1. 카카오 로그인 (Kakao OAuth)

| 항목 | 내용 |
|------|------|
| **서비스 URL** | https://developers.kakao.com |
| **용도** | 소셜 로그인 (카카오 계정) |
| **필요한 키** | REST API 키, JavaScript 키 |

#### 가입 및 설정 절차

1. [Kakao Developers](https://developers.kakao.com)에 접속하여 카카오 계정으로 로그인
2. **내 애플리케이션** > **애플리케이션 추가하기** 클릭
3. 앱 이름, 사업자명 입력 후 생성
4. **앱 키** 메뉴에서 아래 키 확인:
   - **REST API 키** -> `KAKAO_REST_API_KEY` 환경변수로 사용
   - **JavaScript 키** -> `KAKAO_JS_KEY` 환경변수로 사용
5. **카카오 로그인** 메뉴에서 활성화 설정 ON
6. **Redirect URI** 등록: `https://<서비스_도메인>/api/auth/kakao/callback`
7. **동의항목** 설정: 닉네임, 프로필 이미지 등 필요한 항목 동의 설정

### 2-3. LiveKit (실시간 영상/음성 통신)

| 항목 | 내용 |
|------|------|
| **서비스 URL** | https://livekit.io |
| **용도** | WebRTC 기반 실시간 영상/음성 통신 |
| **필요한 키** | API 키, API 시크릿 |

#### 설정 방법

1. LiveKit 서버는 Docker Compose로 자체 호스팅 (`livekit/livekit-server:latest`)
2. API 키와 시크릿은 직접 생성하여 `livekit.yaml`과 백엔드 환경변수에 동일하게 설정
3. LiveKit CLI로 키 생성:
   ```bash
   docker run --rm livekit/livekit-server generate-keys
   ```
4. 생성된 키를 `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` 환경변수로 설정

#### LiveKit 서버 설정 (`livekit.yaml`)

```yaml
port: 7880
rtc:
  port_range_start: 30000
  port_range_end: 30100
  tcp_port: 7881
  use_external_ip: true
  stun_servers:
    - stun.l.google.com:19302

keys:
  <LIVEKIT_API_KEY>: <LIVEKIT_API_SECRET>

logging:
  level: info
```

|------|------|------|------|
| 12 | 게임 페이지 (`/game/:roomId`) | 역할 배정 확인 | 각 플레이어에게 역할(마피아/시민 등)이 배정됨 |
| 13 | 게임 페이지 - 낮 페이즈 | 토론 진행 | WebRTC 영상/음성으로 실시간 토론, 타이머 표시 |
| 14 | 게임 페이지 - 투표 | 의심되는 플레이어 **클릭하여 투표** | 투표 결과에 따라 플레이어 추방 |
| 15 | 게임 페이지 - 밤 페이즈 | 마피아: 대상 선택 / 시민: 대기 | 마피아가 제거할 대상을 선택 |
| 16 | 게임 페이지 | 낮/밤 페이즈 반복 | 승리 조건 달성 시까지 반복 |
